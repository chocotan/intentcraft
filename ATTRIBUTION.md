# Design influences

Intentcraft is a new set of skill instructions, not a repackaging of the
reference projects. Its workflow design draws on these projects:

- [CodeStable](https://github.com/codestable/CodeStable): task ownership,
  decision dependencies, proportional safeguards, durable contracts versus
  temporary progress, and independent review.
- [Compound Engineering](https://github.com/EveryInc/compound-engineering-plugin):
  product framing, grounded alternatives, inherited decisions, requirements
  preservation, prototype feedback, and outcome-sized implementation plans.
- [superpowers](https://github.com/obra/superpowers): collaborative design,
  explicit handoffs, specification coverage, and verification discipline.
- [bigpowers](https://github.com/danielvm-git/bigpowers): fact-versus-choice
  questioning, end-to-end slices, and explicit verification expectations.
